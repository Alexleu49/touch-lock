# Touch Lock — Блокировка сенсора экрана

Android-приложение с плавающей кнопкой поверх всех приложений для мгновенного отключения и восстановления сенсорного ввода экрана.

## Основные возможности
1. **Блокировка в 1 касание**: Нажатие на плавающую кнопку поверх экрана отключает любые касания сенсора, кроме самой кнопки.
2. **Разблокировка повторным нажатием**: Повторное нажатие на кнопку возвращает сенсорный ввод в исходное состояние.
3. **Автоскрытие через 10 секунд**: При отсутствии касаний в режиме блокировки кнопка плавно исчезает.
4. **Восстановление двойным тапом**: Двойное нажатие в любой точке экрана возвращает кнопку назад.

## Автоматическая сборка APK через GitHub Actions

В репозитории настроен автоматический CI/CD воркфлоу (`.github/workflows/build-apk.yml`).

### Как получить готовый .apk файл:
1. Запушьте проект в свой репозиторий GitHub (или нажмите кнопку **«Push to GitHub»** в AI Studio).
2. На странице вашего репозитория на GitHub перейдите во вкладку **Actions**.
3. Выберите воркфлоу **«Build Android APK»**.
4. После завершения сборки (зеленая галочка) прокрутите страницу вниз до раздела **Artifacts**.
5. Нажмите на **TouchLock-Debug-APK** — архив с готовым установочным файлом `.apk` скачается на ваше устройство.

### Ручной запуск сборки:
Во вкладке **Actions** выберите **«Build Android APK»**, нажмите кнопку **«Run workflow»** и выберите ветку `main`.
